## Assessment clarification (Emma B. / Lincoln L.F., 20–21 July)

Per the current unit planner:
- **FT1** – Using Evidence: Embedding Evidence worksheet (self-assessment tool)
- **FT2** – Pre-Planning: students choose an option, break the task into steps, explain and reflect on planning (self-assessment against a rubric)
- **Summative** – Oral presentation (teacher-assessed against rubric)

Issues identified with this approach (Lincoln, 21 July):
1. Embedding evidence isn't relevant until Unit 6 (analytic writing).
2. Metacognition isn't necessarily the best capability fit (ethical or intercultural, surely).
3. No formative tasks to develop speaking and listening skills.
4. No formative tasks that develop reading skills.

Agreed: retool at next LA-A. **Two formal, common formative tasks per UAS.**

## Proposed formative tasks (Lincoln, 22 July)

### Reading FTs
1. **Cold-excerpt inference check** — weekly/fortnightly 10-minute constrained-choice quiz on an unseen passage; self-marking, misread items retaught immediately.
2. **Figurative-to-literal matching** — Lesson 09: match figurative lines to paraphrases plus one justification; answer-key feedback, EAL-friendly.
3. **Annotation sampling with coded feedback** — Week 4: one annotated page per student, returned with a simple code; the next task is to apply the code.
4. **Voice fingerprint match** — Lesson 11, before the voice memo: sort unattributed lines to the correct character, naming one language feature as evidence; self-checking.

### Presentation FTs
5. **Recorded 45-second voice memo** — Lesson 11: in-character recording, teacher gives one coded next step, student re-records applying it.
6. **60-second micro-presentation** — Week 4: small-group in-character delivery; peers check observable behaviours, teacher assesses voice/perspective.

**Recommended minimum:** cold-excerpt inference check + recorded voice memo with re-record.

## Coded feedback (Lincoln, 25 July)

Create a table/code/rubric so feedback isn't repeated student-by-student, e.g. for annotation:

- **Level 1** — You've underlined words in the text. *Next step:* add a symbol — which key idea does this relate to?
- **Level 2** — You've added a symbol that relates to one of the key ideas. *Next step:* add a comment — why have you underlined the text?
- **Level 3** — You've added a symbol and a comment. *Next step:* add a question of your own — why might the author have included this here?
